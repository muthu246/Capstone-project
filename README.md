# Oracle DBA Command Center

A production-focused Oracle DBA portfolio and interactive learning site.

## What is included

- Oracle 10g–19c administration
- RAC and Grid Infrastructure concepts
- Data Guard and disaster recovery
- ASM and storage administration
- Exadata / CellCLI concepts
- GoldenGate
- RMAN / backup and recovery
- Performance troubleshooting
- Interactive Oracle error / incident labs
- Searchable DBA command explorer
- Python DBA automation, cloud migration and Terraform sections

## GitHub Pages

This is a static HTML/CSS/JavaScript site.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/ (root)**.
4. Save.
5. Your expected site URL is:
   **https://muthu246.github.io/Capstone-project/**

The connected GitHub interface used here does not expose the Pages settings API, so Pages must be enabled once in the repository settings.

## Important

The dashboard metrics are simulated portfolio data, not a live database connection. The commands are educational references; validate them against the exact Oracle Database / Grid Infrastructure / Exadata version before production use.

## Files

- `index.html` — site structure
- `style.css` — responsive dark DBA dashboard styling
- `script.js` — interactive labs and command search
